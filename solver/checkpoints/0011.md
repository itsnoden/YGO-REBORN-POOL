## Genuine simulator bug found: Dimension Jar

`Dimension Jar` (`reborn-2228`, passcode `73414375`) was not merely a stale wording row.

Current official behavior restricts each player's selection to up to 3 **monsters** to banish. The pinned upstream Project Ignis implementation used `aux.SpElimFilter` without first requiring `c:IsMonster()`, which could allow non-Monster cards from the GY.

A narrow reviewed override at `solver/script_overrides/c73414375.lua` adds the Monster requirement while preserving the rest of the upstream operation and Spirit Elimination-compatible MZONE/GY handling.

The implementation review is bound to executable SHA-256:
`60678ac2489585d9b4d2b94601ca16c7d50c1123469721235123dacb9be062a4`

Regression coverage is in `solver/tests/test_dimension_jar_override.py`. Solver Verify #197 passed the complete pipeline with this override active.

## Review system

Two distinct accepted review outcomes are now supported:

1. `behavior_equivalent_wording_reviewed`
   - current official text and engine display text differ lexically but are directly reviewed as behaviorally equivalent.

2. `implementation_matches_official_reviewed`
   - engine display text is genuinely stale/non-equivalent, but the exact executable Lua has been directly reviewed/corrected to match current official behavior.
   - additionally bound to the exact `script_sha256`.

All reviews remain bound to Reborn ID, passcode, official-text hash, engine-text hash, and (for implementation reviews) executable script hash. Any relevant future change automatically makes the review stale.

Review sources are merged from:
- `solver/data/reviewed_text_equivalence.json`
- `solver/data/reviewed_implementation_equivalence.json`
- `solver/data/errata_review_batches/*.json`

Duplicate review keys across ledgers are rejected.
